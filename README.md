# Angle Quest

A practice game for Grade 6 maths and science.

**Maths** (`index.html`): sets (Exercises 1.1–1.2), operations on whole numbers (Exercises 2.1–2.3), properties of whole numbers (Exercises 3.1–3.4), integers (Exercise 4.1), fractions (Exercises 5.1–5.4), decimals (Exercises 6.1–6.5), percent (Exercises 7.1–7.2), unitary method (Exercise 8.1), profit and loss (Exercise 9.1), algebraic expressions (Exercises 10.1–10.7), equations and inequalities (Exercises 11.1–11.5), coordinates (Exercise 12.1), point and line (Exercise 13.1), angles (Exercises 14.1–14.3) and triangles, quadrilaterals and circles (Exercises 15.1–15.4), and perimeter, area and volume (Exercises 17.1–17.5), and statistics (Exercises 19.1–19.3), with step-by-step help on every problem. The home page has a fish sea: a fish hatches for each chapter once you start one of its exercises, and grows as you solve its questions. Science chapters join the same sea as birds flying in the sky. Halfway through, each one turns into a surprise animal, and bigger chapters become bigger animals.

It is a plain static site: no build step and no server code.

**Science** (`science.html`): Unit 11.1 Soil, with learn pages, moving pictures, read-aloud, Nepali key words, and practice questions with step-by-step help. Science has its own engine (`science.js`); see [science/README.md](science/README.md).

## Run it on your computer

Open `index.html` in a browser.

## Host it on GitHub Pages

1. Create a new repository on GitHub and upload all the files in this folder, keeping the `lessons` folder.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then press **Save**.
4. After a minute the site is live at `https://<your-user-name>.github.io/<repository-name>/`.
