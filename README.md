# Angle Quest

A practice game for Grade 6 maths: sets (Exercises 1.1–1.2), operations on whole numbers (Exercises 2.1–2.3), properties of whole numbers (Exercises 3.1–3.4), integers (Exercise 4.1), fractions (Exercises 5.1–5.4), decimals (Exercises 6.1–6.5), percent (Exercises 7.1–7.2), unitary method (Exercise 8.1), profit and loss (Exercise 9.1), algebraic expressions (Exercises 10.1–10.7), coordinates (Exercise 12.1), point and line (Exercise 13.1), angles (Exercises 14.1–14.3) and triangles, quadrilaterals and circles (Exercises 15.1–15.4), with step-by-step help on every problem.

It is a plain static site: no build step and no server code.

## Run it on your computer

Open `index.html` in a browser.

## Host it on GitHub Pages

1. Create a new repository on GitHub and upload all the files in this folder, keeping the `lessons` folder.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then press **Save**.
4. After a minute the site is live at `https://<your-user-name>.github.io/<repository-name>/`.
